Task 1 notes: XcodeGen also writes default `CFBundleDevelopmentRegion` and `CFBundleInfoDictionaryVersion`. `Packages/ShareLinkKit/Package.resolved` is committed (AMSMB2 4.0.3, GRDB.swift 7.11.1). Info.plist and entitlements keys live in `project.yml` `properties` so `xcodegen generate` does not drop them.

Task 4 notes: `RemoteEntry` has a public memberwise initializer so it can be constructed outside the module. `failNext` queues errors for the next throwing `SMBClient` call; `disconnect()` increments `disconnectCount` and leaves a pending failure in place. `seedFile` creates missing parent directories.

Task 5 notes: Samba 4.21.9 on Alpine 3.22 accepted `Tests/Samba/smb.conf` unchanged (`testparm` loaded it; `server signing = mandatory` displays as `required`, and `[encrypted]` keeps `server smb encrypt = required`). `list` uses the completion-handler `contentsOfDirectory` because the async overload returns non-Sendable `[URLResourceKey: Any]`. Real connect failures from AMSMB2 4.0.3, for both a wrong password and a closed port, are `NSPOSIXErrorDomain` code 1 (`EPERM`) with `localizedDescription` `Error code 1: ` and `localizedFailureReason` `Operation not permitted`. `SMB2Client.service` destroys the smb2 context before reading `smb2_get_error`, so the `STATUS_LOGON_FAILURE` and `Socket connect failed` texts never reach the mapper. The mapper is unchanged and still maps the plan's unit-test strings (`LOGON_FAILURE` → `.authenticationFailed`, connection-refused `ECONNREFUSED` text → `.serverUnreachable`). On that blank EPERM only, the client probes TCP: a port that does not accept a connection becomes `.serverUnreachable`; a port that does keeps the mapped error, so a wrong password stays `.authenticationFailed`.

Task 10 notes: `NSFileProviderManager.remove(_:mode:)` is `API_AVAILABLE(ios(16.0))` (`FILEPROVIDER_API_AVAILABILITY_V4_0_IOS` in the iOS 27 SDK). The app still checks `#available(iOS 16.0, *)` and falls back to `remove(_:)`. The mode overload's async form returns the preserved-files `URL`; that value is discarded. `domains()`, `add(_:)`, `signalEnumerator(for:)`, `evictItem(identifier:)`, and `getUserVisibleURL(for:)` are the async variants. No `@preconcurrency import`. `ManagedConfigObserver` uses `isolated deinit` because the notification token is not `Sendable`. `DomainInfo` and `ReconcileResult` have public memberwise initializers. `openInFilesURL` replaces the `file` scheme via `URLComponents` and keeps the path (`shareddocuments:///…`). `AppModel` imports `Observation` only, not UIKit or SwiftUI. A sign-in request whose server disappeared is cleared before the next managed server is chosen. Review fix: `ConfiguredShares` and `SignedInShares` count `isManaged` servers only (`feedbackCountsManagedSharesOnly`).

Task 9 notes: `fetchContents` uses `NSFileProviderManager(for: domain)?.temporaryDirectoryURL()` and fails with `NSFileProviderError(.cannotSynchronize)` when the manager is nil or the call throws. The initial-page constants are imported as `NSData`, so the plan's `as Data` comparison is what compiles; the next page is `NSFileProviderPage(rawValue:)`. `Task` cancellation throws `CancellationError`, which is reported as `CocoaError.userCancelled` (`NSUserCancelledError`); other errors go through `FileProviderErrors.nsError`. Completion handlers, `NSFileProviderItem`, `NSFileProviderItemVersion`, and `NSFileProviderManager` are captured as `nonisolated(unsafe)` (not `Sendable`). No `@preconcurrency import`. `DiagnosticLog`'s `NSLock` is held by an `@unchecked Sendable` box. The only extension log line is `provider: no configuration for domain`.

Task 8 notes: No `@preconcurrency import`. `NSFileProviderItem` values are read into `Sendable` fields before the first `await`. `ConnectionProvider` retries `.serverUnreachable` only when `body` throws it on an already-connected client, then reconnects and runs `body` once more. `connect()` throwing `.serverUnreachable` (including the AMSMB2 TCP probe) is not retried; covered by `connectUnreachableIsNotRetried`. A content conflict compares the server's `contentVersion` with `baseVersion.contentVersion`, uploads `"<name> (Conflict …)"` with `overwrite: false`, and re-stats the original so the returned item and the store both keep the server bytes. `ChangeBatch` has an explicit public memberwise initializer because Swift synthesizes an internal one for a public struct. The plan's `Template` and `ItemWithIdentifier` compiled without extra protocol members. Swift Testing warns that the plan's `#require(next)` is redundant; that assertion is unchanged and pagination still returns a 5-item second page with `listCount == 1`.
