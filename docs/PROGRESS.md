Task 4 notes: `RemoteEntry` has a public memberwise initializer so it can be constructed outside the module. `failNext` queues errors for the next throwing `SMBClient` call; `disconnect()` increments `disconnectCount` and leaves a pending failure in place. `seedFile` creates missing parent directories.

Task 5 notes: Samba 4.21.9 on Alpine 3.22 accepted `Tests/Samba/smb.conf` unchanged (`testparm` loaded it; `server signing = mandatory` displays as `required`, and `[encrypted]` keeps `server smb encrypt = required`). `list` uses the completion-handler `contentsOfDirectory` because the async overload returns non-Sendable `[URLResourceKey: Any]`. Real connect failures from AMSMB2 4.0.3, for both a wrong password and a closed port, are `NSPOSIXErrorDomain` code 1 (`EPERM`) with `localizedDescription` `Error code 1: ` and `localizedFailureReason` `Operation not permitted`. `SMB2Client.service` destroys the smb2 context before reading `smb2_get_error`, so the `STATUS_LOGON_FAILURE` and `Socket connect failed` texts never reach the mapper. The mapper is unchanged and still maps the plan's unit-test strings (`LOGON_FAILURE` → `.authenticationFailed`, connection-refused `ECONNREFUSED` text → `.serverUnreachable`). On that blank EPERM only, the client probes TCP: a port that does not accept a connection becomes `.serverUnreachable`; a port that does keeps the mapped error, so a wrong password stays `.authenticationFailed`.

Task 10 notes: `NSFileProviderManager.remove(_:mode:)` is `API_AVAILABLE(ios(16.0))` (`FILEPROVIDER_API_AVAILABILITY_V4_0_IOS` in the iOS 27 SDK). The app still checks `#available(iOS 16.0, *)` and falls back to `remove(_:)`. The mode overload's async form returns the preserved-files `URL`; that value is discarded. `domains()`, `add(_:)`, `signalEnumerator(for:)`, `evictItem(identifier:)`, and `getUserVisibleURL(for:)` are the async variants. A sign-in request whose server disappeared is cleared before the next managed server is chosen. Review fix: `ConfiguredShares` and `SignedInShares` count `isManaged` servers only (`feedbackCountsManagedSharesOnly`).
